# 本地分组与智能体选择

侧栏分组只保存当前客户端的视觉分类。每个智能体或既有群聊可归属于一个本地分组，移动时从原分类移出。智能体仍可参加多个真实群聊；本地分类不修改聊天成员、运行设备、权限或调度方式。

- 分组可新建、双击标题原地重命名、右侧箭头折叠、删除。重命名 Enter 保存、Escape 或失焦取消，输入法组合期间不提交。删除仅解除分类，实体仍出现在未分组与搜索中。
- 每组最多一个智能体标为主力，允许暂不选择；选择新的主力会替换旧标记；群聊不能标为主力。标记不赋予权限，也不自动发送指令。
- 搜索涵盖分组名、智能体与群聊名，暂时展开匹配折叠组，清空搜索后保留原折叠偏好。
- 存储按已同步本地服务端点与身份 ID 隔离。未知身份、连接重建或快照同步失败时不读取或写入旧分类。新身份不继承旧分组。
- 本地存储失败明确提示，不声称保存成功；损坏数据不自动覆盖。关闭应用后同一账号可恢复分类，不同步其他设备。
- 点击智能体打开现有单聊，或准备新的聊天草稿。点击已有群聊只导航。导航仍遵循正常聊天客户端的观看/已读行为；分组编辑本身不发送 RPC。
- 重复点击当前智能体不重置同一草稿或释放附件。

新聊天使用可搜索的头像选择浮层；既有聊天不重复显示收件选择器。选择仅切换本地目标，不更改智能体配置或自动发消息。支持键盘、Escape 返回焦点、视口内滚动和真实头像安全渲染。

所有测试使用合成实体。真实账号分类、消息发送及用户系统剪贴板不属于自动验收操作。

## 最近与团队

侧栏顶部在“最近”和“团队”之间切换，视图与日期折叠偏好按账号独立保存在本机，不改变正文、草稿或选中聊天。最近使用已知消息最大创建时间（无消息时为聊天创建时间），按本地日界分为今天、此前两天、此前四天、其余历史四个不重复桶。“全部”指其余历史，悬停说明具体范围。

团队页中的“团队”是本地视觉分类；Solo 仅列未归组独立智能体，未分组群聊有单独区段。搜索暂时展开匹配的折叠项，并保留聊天搜索结果；清空搜索恢复原折叠状态。

旧版本有效的双主力记录稳定保留第一位，组名、全部成员与折叠状态不变，读取不自动覆写存储。后续用户编辑正常保存为单主力格式。群聊不参与主力选择。

可把智能体或群聊在明确分组和未分组区域间拖动；移动主力会清除原组主力标记，不自动选新主力。拖动只接受本树、同账号、当前实体的一次性短期令牌，外部文字或文件不视为成员，空白处放下无操作。现有整理菜单仍提供键盘可达的移动方式。拖动不打开聊天、不发 RPC、不变更真实群聊成员。
