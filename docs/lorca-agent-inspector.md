# 智能体详情与例行任务

右侧检查器查看实际智能体，独立滚动。群聊显示可选择的智能体卡片；切换查看对象不会更改聊天收件人或 Runner。外部切换聊天时，未保存的资料或权限草稿先留在原对象，并明确提示，保存或取消后再跟随聊天。账号变化立即清空编辑上下文。

## 资料、创建与头像

名称、说明、服务商、模型、思考强度和运行设备通过 `bots.update` 保存，影响该智能体的所有聊天。表单保留草稿，保存前展示明确的智能体和变更范围；取消不写。随机 revision 是一次性提交票据，配置 version 是内容版本，两者用途不同。

新建使用 `bots.create`，仅可选择当前库存中已知的 macOS/Linux/Windows Runner；手机和未知设备不能作为创建目标。创建会生成智能体及其单聊，但不会自动发送消息。后端默认能力及风险在原生确认中明确展示。Runner 变更不会迁移工作区、记忆或正在运行的任务。

自定义头像通过本机文件选择器进入主进程，经普通文件、大小、尺寸、文件稳定性校验后，由 nativeImage 解码、裁切并重编码成至多 512px 的方形 PNG。临时文件保持私有；只有在隔离预览窗口和最终确认后才提交。取消会清理临时文件；恢复默认头像需明确确认。普通聊天 renderer 不接收文件路径、原文件名或预览字节，只接收最终状态。

## 记忆与笔记

官方“笔记”对应该智能体 Runner 工作区的 `MEMORY.md`，没有另一个独立 `bot.notes` 字段。主界面只显示行数、字节数、加载预算、主题和日志数量，不接收正文或工作区路径。

“编辑记忆”在隔离的原生窗口读取完整正文。允许编辑文件上限为 256 KiB；200 行/24,000 字节是模型每轮自动加载预算，不等同于文件编辑上限。超预算提示不会截断正文。保存使用读取时的 `expected_hash`，正文已变化则必须重新读取并合并，不能无 hash 覆盖。原有 CRLF 在未修改时保留。完整变更过长时先在隔离复核窗展示，再请求系统确认。

## 例行任务

参考源码固定为 `egoist/lorca@37aa019188f33ec0843dd67785edc50d3eaf2cb6`。例行任务归属于智能体，配置随账号同步，由该智能体当前 Runner 执行。

- 普通间隔、cron、单次计划支持读取、创建、编辑、独立启停、请求立即运行和删除。
- 计划通过 `routines.describe` 在原生提交确认前只读校验，并展示服务端解释、时区和下一次计划时间。
- 编辑配置与启停分别提交，不假装为一个原子事务。
- `routines.run` 的成功只表示“已请求运行”，不表示任务完成；最终运行状态来自重新读取的后端数据。
- 检查器打开时，`roster.changed` 以及选中智能体的 `job.started`/`job.finished` 事件合并触发只读刷新；关闭后取消等待，不建立无止境轮询。用户也可手动刷新。
- 暂停和删除不会取消已运行任务；立即运行可能执行已暂停计划的任务。
- 带检查脚本的任务、PR 和日历触发器的配置暂为只读：固定 API 的 `routines.update` 不处理检查脚本更新，PR/日历创建还需要相应已授权插件和运行设备。不会展示可保存却被后端忽略的字段。
- 工作流创建任务的启用仍受后端审阅门槛约束。客户端不自动批准工作流或扩大权限。

## 插件与授权范围

插件目录来自选中智能体 Runner 的 `bots.permissions`，缓存目录不等于实时可用性。查看或修改某个智能体的插件授权不会卸载插件、修改服务商密钥或迁移 Runner。

`read`、`draft`、`write` 是独立能力范围，工具还须满足明确工具名单；空范围或空名单代表未授权。全部工具包含该实例未来新增的工具，因此确认窗口明确提示。`bots.update.permissions` 是整体策略替换，主进程保留其他实例以及 filesystem/shell/drafts 字段，不依赖会扩大权限的默认值。由全部插件开放改为明确列表时，未来新插件不自动获权，这一范围变化会在保存前说明。

## 安全与结果处理

所有编辑保留主窗口来源、主 frame、身份、连接世代、端点、认证方式和选中对象校验。敏感编辑窗口保持独立 session、sandbox、contextIsolation、无 Node、无外网资源或任意导航。PNG 预览由可信主进程验证后进入只读窗口规格；不能声称 CSP 的 `data:` 本身具有 PNG MIME 限制。

保存前后重新读取配置并校验内容版本。上游缺少通用 CAS，因此最后一次检查与写入之间仍有竞态窗口；不声称多客户端事务隔离。未知结果不会自动重试，保留草稿并要求读回核对。资料、记忆、任务和插件是独立操作，不承诺跨模块全有或全无。

自动测试仅使用合成账号、文件、任务和本地 mock 服务。代码实现不意味着已对真实账户创建任务、上传头像、修改记忆或扩大持久访问。
